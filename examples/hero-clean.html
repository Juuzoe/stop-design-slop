What it actually does

Three jobs, and it does not try to be your design system.

Drift detection

Polls the Figma Variables API every 60 seconds and diffs it against your tokens.css. Catches renames, not just value changes.

Pull requests, not dashboards

Every change arrives as a PR against your repo with the before and after swatches inline. Review it where you review everything else.

Contrast checks on merge

Blocks a token change that would drop any shipped text pair below 4.5:1. The failing pair is named in the check output.

Built by two people in Kraków. Email hi@flowsync.dev, we answer within a day.

Not built for teams over 200 designers. We optimize for small files and fast syncs.
